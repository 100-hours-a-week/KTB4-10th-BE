# 개인정보 처리방침

> V1 개발용 초안입니다. 실제 공개 전 운영 주체, 개인정보 보호책임자·문의처, 위탁·국외이전 현황과 시행일을 확정하고 법률 검토를 받아야 합니다.

## 1. 처리하는 개인정보와 목적

| 구분 | 항목 | 목적 |
| --- | --- | --- |
| 카카오 로그인 | 카카오 회원번호, 닉네임, 프로필 이미지, 이메일(제공되는 경우) | 회원 식별, 로그인, 프로필 표시 |
| 회원 설정 | 여행 취향, 표시 언어, 푸시 수신 설정 | 가이드북 생성과 개인 설정 제공 |
| 서비스 이용 | 가이드북 생성 요청과 결과, 관심·알림 등 서비스 이용 기록 | 서비스 제공, 이용 기록 복구와 문의 대응 |
| 자동 생성 정보 | 서비스 세션 식별값, 접속 기록, IP·브라우저 정보 | 로그인 유지, 보안과 장애 대응 |

이메일은 카카오에서 제공되지 않을 수 있으며, 서비스는 제공받지 않은 이메일 입력을 강제하지 않습니다.

## 2. 보유 및 이용 기간

- 회원 정보와 서비스 데이터는 회원 탈퇴 시까지 처리합니다.
- 탈퇴 시 로그인 세션을 즉시 폐기하고, 일반 서비스 데이터는 현재 V1 정책에 따라 30일 보관 후 삭제하거나 비식별화합니다.
- 보안·장애 대응 기록이나 법령상 보존 의무가 있는 정보는 해당 목적과 기간 동안 분리 보관할 수 있습니다.

## 3. 제3자 제공과 처리위탁

- 개인정보를 제3자에게 제공하는 기능은 현재 V1 범위에 포함하지 않습니다.
- 서버·클라우드 등 처리위탁이나 국외이전이 발생하는 경우 실제 운영 사업자, 업무 내용, 이전 국가와 보유 기간을 확정하여 이 방침에 공개합니다.

## 4. 정보주체의 권리

- 회원은 서비스에서 자신의 정보를 조회하고 취향·푸시 설정을 변경하거나 탈퇴할 수 있습니다.
- 개인정보 열람·정정·삭제·처리정지 요청과 문의 방법은 실제 공개 전 확정할 개인정보 문의처를 통해 안내합니다.

## 5. 쿠키와 안전성 확보조치

- 서비스는 로그인 유지와 요청 위조 방지를 위해 서비스 세션 쿠키와 CSRF 토큰 쿠키를 사용합니다.
- 세션 원문 대신 해시값을 저장하고, 운영 환경에서는 HTTPS와 보안 쿠키 설정을 적용합니다.
- 접근 권한 제한, 로그 점검과 보안 업데이트 등 개인정보 보호를 위한 관리적·기술적 조치를 적용합니다.

## 6. 개인정보 보호책임자와 시행일

운영 주체, 개인정보 보호책임자, 문의처와 시행일은 실제 서비스 공개 전에 확정하여 표시합니다.
