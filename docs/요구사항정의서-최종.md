# 요구사항 정의서 최종본

> 2026-11-24 · 백엔드 `dev` (`277bd55`) 기준

KGB는 지도에서 국내 관광지와 행사를 탐색하고 여행 조건에 맞는 AI 가이드북을 만들어 보관하는 서비스다.

## 서비스 요구사항

| 영역 | 사용자 흐름 | 주요 규칙 |
|---|---|---|
| 계정 | 카카오 로그인 → 기본 여행 취향 설정 → 서비스 이용 | 서버 세션으로 로그인 상태를 유지한다. 회원은 취향과 푸시 설정을 변경하고 계정을 탈퇴할 수 있다. |
| 탐색 | 지도와 목록에서 장소·행사 탐색 → 상세 보기 → 관심 장소 저장 | 검색, 지역·카테고리 필터, 지도 범위 조회, 일자별 신규 행사를 제공한다. 관심 장소는 회원별로 관리한다. |
| 최초 생성 | 여행 지역·날짜·동행 유형·인원 입력 → 진행 확인 → 가이드북 열람 | 등록된 기본 취향과 선택 입력인 추가 요청을 반영한다. 여행 기간은 양끝 포함 1~7일이며, 생성권과 입력 조건을 확인한다. |
| 재생성·재시도 | 결과에 피드백을 제출해 일정을 개선하거나, 실패한 작업을 다시 시도 | 재생성은 자연어 피드백으로 접수한다. 다시 시도할 수 있는 실패 작업은 동일 작업 ID에서 최대 3회 재시도할 수 있다. 생성 및 재생성 요청에는 멱등 키가 필요하다. |
| 보관 | 내 가이드북 목록 → 상세 일정 및 HTML 열람 → 보관 목록에서 삭제 | 회원의 활성 보관 관계를 확인한다. 생성 진행은 SSE와 상태 조회에서 확인할 수 있다. |
| 알림 | 미읽은 알림 확인 → 개별 또는 전체 읽음 처리 | 인앱 알림은 SSE로 구독한다. 웹 푸시는 브라우저 구독 및 서버 설정이 필요하다. |
| 생성권 | 잔액 조회 → 가이드북 생성 또는 운영 쿠폰 등록 | 가입월에 3개를 지급한다. 매월 1일 잔액이 3개 미만이면 3개까지 보충한다. 최초 생성 완료와 생성권 차감은 같은 트랜잭션에서 처리한다. |

## 외부 데이터와 연동

- TourAPI의 관광 콘텐츠, 이미지, 행사 기간을 동기화한다. AI에는 요청 지역과 여행 기간에 적합한 후보를 전달한다.
- AI의 이벤트를 받아 작업 상태와 결과를 저장한다. 기본 전달 모드는 HTTP이며, 배포 설정에 따라 MQ Outbox 경로를 활성화할 수 있다.
- 정책 안내는 별도의 목록과 상세 조회로 제공한다.

## 후속 설계 항목

공유 링크와 가이드북 가져오기, 독립 일정 조회 API, 서버 PDF 내보내기, 평가·랭킹, 회원 대상 생성권 원장 조회, 상품 주문·PG 결제는 후속 설계로 관리한다.

세부 요구사항 ID와 이전 합의는 [기존 요구사항 정의서](./요구사항정의서.md)에 남겨 둔다. 현재 요청·응답과 데이터 구조는 [V3 API 명세서](./V3%20API%20명세서.md), [테이블 정의서 최종본](./테이블정의서-최종.md), [ERD](./KGB-ERD-최종.png)에서 확인할 수 있다.
